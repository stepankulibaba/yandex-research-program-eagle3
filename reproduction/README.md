# Воспроизведение EAGLE-3 и скорость

**Вопрос.** Сколько реально даёт EAGLE-3 на LLaMA-3.1-8B-Instruct, если взять официальный драфт авторов? Насколько быстрее оптимизированный движок (SGLang, через него NeMo отдаёт драфты) и тренер NeMo AutoModel по сравнению с кодом статьи? Хватит ли 100 GPU-часов, чтобы обучить драфт с нуля?

Задачи команды:
- **3a** — код статьи;
- **3b** — SGLang;
- **4** — скорость обучения: код авторов против NeMo;
- **5** — бюджет GPU-часов.

Всё считается на одной H200.

## Что получилось (предварительно)

Задача 3a, код авторов без изменений, 5 бенчмарков по 80 вопросов. **Внимание:** этот прогон шёл на дереве EAGLE-2. Скрипт оценки по умолчанию берёт `--depth 5`, а для EAGLE-3 в статье глубина 8, то есть `--depth 7`. Перепрогон с правильной глубиной идёт.

| | статья: ускорение / τ | у нас, `--depth 5`: ускорение / τ |
|---|---|---|
| MT-bench | 4,40× / 6,13 | 3,12× / 5,54 |
| HumanEval | 4,85× / 6,74 | 3,33× / 5,78 |
| GSM8K | 4,48× / 6,23 | 3,25× / 5,59 |
| Alpaca | 4,82× / 6,70 | 3,43× / 5,89 |
| CNN/DM | 3,65× / 5,34 | 2,69× / 4,96 |
| **среднее, T = 0** | **4,44× / 6,23** | **3,16× / 5,55** |
| среднее, T = 1 | 3,48× / 4,92 | 2,62× / 4,52 |

Ускорение равно τ, делённому на стоимость цикла EAGLE в шагах обычной генерации. Разрыв по ускорению (0,71 от статьи) раскладывается на две части:
- **τ ниже на ~10 %** — в том числе из-за более мелкого дерева;
- **цикл дороже:** 1,7–1,8 обычного шага против 1,4 у авторов. На H200 обычная генерация быстрая (около 90 токенов/с, 11 мс на токен), а накладные расходы цикла EAGLE — Python и мелкие операции с деревом — почти не сокращаются.

## Как запускать

Код — в [`code/`](code/). Две папки должны лежать рядом: `inference_speed` (оркестратор и инференс) и `nemo_speed` (обучение).

```bash
cd code/inference_speed && NIGHT_SECONDS=26400 nohup setsid bash night.sh > night.out 2>&1 &
```

Один запуск сам ставит окружения, качает закреплённые версии моделей и кода и проходит все стадии. Готовые стадии при перезапуске пропускаются. Упавшая стадия не останавливает остальные.

Где итоги:
- `results/main/summary.md` — 3a и 3b;
- `../nemo_speed/artifacts/main/summary.txt` — задача 4;
- `results/main/budget.md` — задача 5.

Протокол подробно описан в [`code/inference_speed/README.md`](code/inference_speed/README.md), история исправлений — в [`FIXES.md`](code/inference_speed/FIXES.md).
