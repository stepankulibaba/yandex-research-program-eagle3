# Скорость обучения EAGLE-3 (задача 4)

Здесь лежит то, что относится только к обучению:
- `prepare_data.py` — общие для двух тренеров данные: 1000 примеров, токенизированных функцией авторов, и словарь драфта на 32K;
- `patch_original.py` — копия тренера авторов, подправленная для замера.

Запускает всё оркестратор из соседней папки:

```bash
bash run.sh            # только обучение: тренер авторов, NeMo и его ускорения
SMOKE=1 bash run.sh    # то же на 40 примерах
```

Итог — `artifacts/main/summary.txt`. Как устроен замер и что именно сравнивается — в [../inference_speed/README.md](../inference_speed/README.md).
