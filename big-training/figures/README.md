# Графики: каталог для отбора в презентацию

Все графики строятся заново из `results/llama31-8b/` скриптами:
- `make_results_figures.py` — файлы без префикса;
- `make_extra_figures.py` — файлы с префиксом `x_`;
- `make_incident_figures.py` и `make_diag_figure.py` — инцидент NeMo.

Цвета везде одни:
- серый — официальный драфт авторов;
- зелёный — `baseline` (слои 2/16/29);
- синий — `ours` (16/22/29 + `fc_norm`).

★ — кандидаты на главный слайд.

## Главный результат

| файл | что показывает |
|---|---|
| ★ `real_tau_delta.png` | Реальная τ ours − baseline с 95 % интервалами по пяти бенчмаркам. В среднем +0,037, значимо; на диалогах +0,08…+0,09. |
| ★ `real_tau.png` | Реальная τ трёх драфтов по бенчмаркам (SGLang), чёрные штрихи — код авторов. |
| ★ `val_tau.png` | τ-оценка на валидации по ходу обучения и разница: ours впереди в 35 точках из 35. |
| `x_real_tau_milestones.png` | Реальная τ на промежуточных чекпоинтах (каждые 80 тыс. диалогов) против официального драфта. |
| ★ `x_real_tau_milestones_delta.png` | Реальная τ ours − baseline на каждом чекпоинте: на MT-bench и Alpaca ours впереди в 7 из 7. |
| `x_val_vs_real.png` | τ-оценка на валидации против реальной τ: корреляция внутри бенчмарка 0,994–0,999, дешёвая метрика работает. |

## Почему наши слои работают

| файл | что показывает |
|---|---|
| ★ `x_layer_contribution.png` | Доля выхода `fc` от каждого слоя цели. Baseline: слой 2 — 1,8 %, слой 29 — 83 %. Ours: 30 / 26 / 44 %. |
| `x_layer_contribution_training.png` | Те же доли по ходу обучения. |
| ★ `x_state_norms_fc_norm.png` | Норма признаков растёт с глубиной (1,5 у слоя 2 против 38 у слоя 29) и масштабы `fc_norm` у ours. Объясняет, почему без нормировки нижний слой не используется. |
| `x_val_position_gap.png` | Тепловая карта разницы точности по позициям цепочки и по ходу обучения: выигрыш на позициях 2–7. |
| `acc_by_position.png` | Точность по позициям в точке сравнения у трёх драфтов. |
