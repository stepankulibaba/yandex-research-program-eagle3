# Выбор слоёв target для драфта

**Вопрос.** В EAGLE-3 вход драфта — `W·[h_2; h_{N/2}; h_{N−3}]`, слои зашиты в код для любой модели. Почему эти слои, какие лучше, помогает ли роутер / MoE (без роста числа параметров)?

| Часть | Что сделали | Статус |
|---|---|---|
| [frozen/](frozen/) | Драфт заморожен: абляции официальных драфтов, перебор слоёв, переобучение только входа fc, MoE | готово (DSL-8B, Qwen3-1.7B) |
| [router/](router/) | Драфт обучается целиком; роутер выбирает top-2 / top-3 слоя (статически или для каждого токена) | Qwen3-1.7B готово; DSL-8B идёт |

Отчёты: [слои, замороженный драфт](reports/eagle3_layers.pdf) · [роутер, размороженный драфт](reports/eagle3_routed.pdf) · [схема MoE-вариантов](reports/method5_scheme.pdf)

## Результаты

**Замороженный драфт** (τ по протоколу статьи):
- Без слоя 2 τ падает на 2 % (DSL) и 6 % (Qwen); без N−3 — на 40–68 %. Слой 2 почти не используется.
- Лучший одиночный слой — около 0,7N (DSL: 23, Qwen: 20).
- Qwen, переобучение только входа: (2, 14, 25) с нуля 3,37 → + нормализация 3,68 → **(14, 20, 25) + нормализация 3,80**. Смесь всех слоёв и MoE не лучше этой тройки.

**Драфт обучается целиком, Qwen3-1.7B** (цепочечная τ, 240 вопросов, 95 % CI):

| Вариант | τ | Δ к оригиналу |
|---|---|---|
| оригинал (2, 14, 25) | 3,05 | — |
| + нормализация каждого слоя | 3,21 | +0,16 |
| **(14, 20, 25) + нормализация** | **3,29** | **+0,24** [0,22; 0,26] |
| статический роутер top-3 → слои (21, 24, 27) | 3,24 | +0,19 |
| статический роутер top-2 → слои (25, 26) | 3,16 | +0,11 |
| пословный роутер top-3 / top-2 ⚠️ | 3,00 / 3,14 | −0,05 / +0,09 |

⚠️ У пословного роутера в этом запуске выбор застывал в первые десятки шагов (слишком крупный шаг для входа размерности H). Исправлено (`token_top*_s`, вход / √H, lr 1e-3); исправленная версия считается на DSL-8B.

## Выводы (пока по Qwen; DSL-8B — в процессе)

1. Нужная зона слоёв — около 0,7N и около N−3; слой 2 занимает слот зря.
2. Нормализация каждого слоя перед склейкой — самый дешёвый выигрыш (+59 тыс. параметров, ноль затрат на инференсе).
3. Статический роутер сам находит эту зону без ручного перебора.
4. Выигрыш сокращается по ходу обучения (+0,45 → +0,25), при полном объёме данных статьи может быть меньше.
5. Обучаемый драфт стартует с весов под оригинальные слои — это даёт оригиналу фору (особенно заметно на сильном драфте DSL).
