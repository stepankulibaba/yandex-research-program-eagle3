# Роутер слоёв при обучаемом драфте

Вместо фиксированной тройки модуль выбирает **k из N+1** состояний target, нормирует, склеивает и сжимает матрицей `W` (k·H → H), как в оригинале. Драфт обучается целиком (6-шаговая развёртка, как training-time test), target заморожен. Все 7 вариантов учатся параллельно на одних данных.

| Вариант | Слои |
|---|---|
| `fixed_raw` | (2, N/2, N−3), как в EAGLE-3 |
| `fixed_norm` | то же + RMSNorm каждого слоя |
| `fixed_alt` | (N/2, 0.7N, N−3) + нормализация |
| `static_top3/2` | одна обучаемая оценка на слой, k лучших для всех токенов |
| `token_top3/2_s` | роутер `Linear(H→N+1)` выбирает k слоёв для каждого токена |

## Файлы (читать в этом порядке)

`fusion.py` (выбор слоёв) → `draft.py` (драфт EAGLE-3 и развёртка) → `train.py` (обучение, оценка) → `metrics.py` (τ) → `prepare_data.py`, `final_eval.py` (240 вопросов), `sanity.py` (код воспроизводит официальный драфт), `probe.py` (обнуление g / эмбеддинга), `analyze.py`, `make_report_figures.py`.
`original/` — код, на котором шёл запуск Qwen; `check_equivalence.py` подтверждает, что читаемая версия даёт побайтно те же числа.

## Запуск

```bash
bash run_dsl.sh          # окружение, модели, данные, sanity, обучение, итоговая оценка → results_dsl-8b.tgz
```
Обучение сохраняет состояние каждые 2000 шагов (`results/<pair>/resume.pt`) и продолжает с него при перезапуске.

## Результаты

- `results/qwen3-1.7b/` — `history.json` (τ и выбор слоёв по ходу обучения), `final_eval.pt` (240 вопросов), `report_stats.json`; графики в `figures/`.
- DSL-8B (N=32): идёт. Официальный драфт через наш код: цепочечная τ 4,24 (sanity OK). Предварительно после 1 эпохи впереди оригинал (3,15), роутеры выбирают ~0,7N и верхние слои (22, 26, 30).
