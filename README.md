# yandex-research-program-eagle3

Воспроизведение и исследование EAGLE-3 (спекулятивное декодирование), Yandex & Sirius Research Program 2026.

## Направления

| Папка | Вопрос | Статус | Главное |
|---|---|---|---|
| [layer-selection](layer-selection/) | Какие слои target подавать драфту; нужен ли роутер / MoE | Qwen3-1.7B — готово, DSL-8B — идёт | Слои (N/2, 0.7N, N−3) + нормализация: +8 % τ; слой 2 не нужен; MoE не дал прироста |
| [extra-checks](extra-checks/) | Языки, публичные драфты, воспроизводимость | готово | Вне английского ускорение почти пропадает (τ ≤ 1/p); данные важнее архитектуры драфта |

## Как устроен репозиторий

- **Одна папка — одно направление.** Внутри: `README.md` (вопрос → что сделали → результат → вывод → статус), код, `results/` (json и логи), `figures/`, `reports/` (PDF).
- **Новое направление** — новая папка с README по тому же шаблону и строка в таблице выше.
- **В git не кладём** модели, сгенерированные данные и чекпоинты (см. `.gitignore`); только код, небольшие результаты и графики.

## Общий стенд

| Target | Драфт | N слоёв |
|---|---|---|
| DeepSeek-R1-Distill-Llama-8B (DSL-8B) | официальный драфт авторов EAGLE-3 | 32 |
| Qwen3-1.7B | AngelSlim/Qwen3-1.7B_eagle3 | 28 |
| Qwen3-8B | 11 публичных драфтов (extra-checks) | 36 |

**τ** — сколько токенов в среднем получается за одну проверку target-моделью (больше — быстрее). Протокол статьи: MT-bench, GSM8K, HumanEval, temperature 0, дерево 60 / глубина 5 / top-k 10. Для обучения вариантов используется более быстрая офлайн τ по цепочке глубины 6 (совпадает с реальной генерацией EAGLE в режиме цепочки с точностью 0,01; по дереву τ выше).

Репозиторий EAGLE: `SafeAILab/EAGLE`, коммит `cb7e0841`.
