# Происхождение кода и идеи

- [NVIDIA NeMo Automodel](https://github.com/NVIDIA-NeMo/Automodel/tree/3914f200a4c782d44b58ee7a01b4685e4158e19c): определения драфта, TTT, распределения цели и функции потерь. `nemo_ttt_runtime.py` извлекает проверенные определения из исходников по SHA-256, без установки полного пакета. `stride_soft_cross_entropy.py` производен от ядра NeMo; сохранены уведомление NVIDIA и лицензия Apache-2.0. Изменения касаются адресации срезов `[B,S,V]` с раздельными шагами строк и элементов пакета.
- [SafeAILab/EAGLE](https://github.com/SafeAILab/EAGLE/tree/cb7e0841fe0c206c6ed74a197ad5e2a1f13f5a2b): дерево драфта, его загрузка и проверка принятия. Исходники скачиваются отдельно; их лицензия проверяется вместе с кодом. В репозиторий они не копируются.
- [SpecForge](https://github.com/sgl-project/SpecForge/blob/53398a8f01ae47175bee8459c5b5cca3848c8a7e/specforge/algorithms/eagle3/model.py): общий буфер вероятностей со срезами уже встречается в этом коде. Концептуальная новизна такого буфера не заявляется. Вклад этой ветки: адаптация к проверенному пути NeMo, проверка градиентов и обновлений, измерения памяти и доработка Triton для пакета из нескольких последовательностей.

Код коллег из других направлений не включён. Архивные скрипты этой ветки перенесены с изменением путей; их первоначальные контрольные суммы сохранены в `export_manifest.json`. Локальные численные результаты ограничены протоколом в `reports/PROTOCOL.md`.
