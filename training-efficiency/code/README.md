# Код и воспроизведение

`analyze_results.py` проверяет опубликованные счётчики: бюджет четырёх обучений, парные эффекты и интервалы H27–H29, 200 точных повторов факторного опыта, кривую обучения, время и вместимость серии памяти. Ему достаточно стандартной библиотеки Python. Полные события деревьев заменены их контрольными суммами; по этим файлам нельзя восстановить токены или пересчитать модель.

`make_figures.py` строит два графика из тех же JSON. Нужен `matplotlib`.

`original/` содержит код, использованный в вычислениях, и необходимые локальные зависимости. При переносе изменены только пути. Вычисления не переработаны; исходные и текущие SHA-256 приведены в [export_manifest.json](export_manifest.json).

## Проверки без видеокарты

```bash
python3 training-efficiency/code/analyze_results.py
python3 training-efficiency/code/make_figures.py
python3 training-efficiency/code/prepare_sources.py
python3 training-efficiency/code/check_cpu.py
```

Последние две команды требуют `torch` и `transformers`. Они проверяют 26 случаев оптимизатора, 32 расписания бюджета, 64 сравнения с авторской проверкой принятия и 9 сравнений функции потерь и градиентов с общим буфером на маленькой случайной модели. Это CPU-проверки FP32; проверку ядра Triton они не заменяют.

`prepare_sources.py` скачивает 35 файлов NeMo/EAGLE по закреплённым версиям и проверяет их SHA-256. Модели и датасеты не скачиваются. Файлы помещаются в игнорируемые `Automodel/` и `EAGLE/` внутри направления.

## Граница полного повторения GPU-опыта

Веса моделей, исходный пул запросов, сгенерированные ответы, тензорные кэши, контрольные состояния и манифесты очереди остаются вне репозитория. Архивные GPU-скрипты зависят от этих проверенных входов: один клон этой ветки не повторяет обучение целиком. Приведённые команды воспроизводят анализ опубликованных результатов и небольшие проверки кода.

Для полного повторения нужны новые манифесты входов и расписания после переноса путей; старые контрольные суммы подменять нельзя. Веса скачиваются из указанных в метаданных публичных моделей по закреплённым версиям. Для Triton нужен Linux/CUDA и полный клон указанной версии NeMo с зависимостями; минимального набора AST-исходников недостаточно.

Зафиксированное окружение дообучения: PyTorch `2.6.0+cu124`, FP16 eager. Окружение памяти: PyTorch `2.11.0+cu128`, Transformers `4.53.1`, Triton `3.6.0`, Tesla T4. Новые замеры в других окружениях считаются отдельным опытом.
