# Дополнительные проверки

Отчёт: [eagle3_summary.pdf](reports/eagle3_summary.pdf)

| Проверка | Результат |
|---|---|
| **Воспроизводимость** | DSL-8B: τ 5,28 / 6,08 / 5,84 (MT-bench / GSM8K / HumanEval) против 5,58 / 6,93 / 6,38 в статье. Официальный скрипт обрезает ответ на 512 токенах вместо заявленных 1024 |
| **Языки** (DSL-8B / Qwen3-1.7B) | англ. τ 5,34 / 3,65; рус. 1,62 / 1,71; яп. 1,97 / 1,77 — на японском DSL медленнее обычной генерации (0,67×). Причина — словарь драфта 32 тыс.: вне его 33–61 % токенов, и τ ≤ 1/p |
| **11 публичных драфтов для Qwen3-8B** | τ от 2,6 до 4,8 при одном target; режим рассуждений стоит 4–33 % τ |
| **Данные против архитектуры** | драфты на одних данных с разной архитектурой совпадают по τ ±0,02; разные данные — разница почти вдвое |
| **Геометрия** | независимые драфты читают из target похожие направления (перекрытие 0,2–0,6 против 0,016 у случайных); 80–96 % сигнала входа — из слоя N−3 |
